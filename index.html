Home Lab

Current Focus · Infrastructure

12U Micro-Datacenter

This 12U portable rolling network rack is a self-contained, low-power micro-datacenter optimized for game hosting, network deployment, and automated media archiving.

Built around dual Dell Small Form Factor nodes, it runs on a dedicated 1Gbps local switching loop with automated UPS battery protection to safeguard live databases from sudden power loss.

  • Main Server Node: Dell Precision 3430 running a RAM-allocated PaperMC Minecraft server and a Clonezilla/DRBL PXE deployment hub for sequential client laptop imaging.
  • Storage Node: Dell OptiPlex NAS with a multi-drive array for centralized Clonezilla images and automated rolling backups of live Minecraft worlds.
  • Media Archive Pool: Dedicated storage for organizing and preserving local copies of long-form YouTube and Twitch media archives.
