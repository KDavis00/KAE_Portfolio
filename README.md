# KAE CREATIVE — Art × Tech Portfolio

A responsive portfolio combining art, photography, IT, networking and homelab projects.

## Project Files
- `index.html` contains the portfolio layout, gallery sections, and image content.
- `style.css` contains the visual design, responsive layout, themes, and expandable categories.
- `script.js` controls Creative / Tech mode switching and the image lightbox.

## Image Folders
- Environment images are in `images/environment/Travel/Spain/`.
- Additional Environment folders include `images/environment/Living/` and `images/environment/Orange/`.
- Pet images are in `images/pets/`.
- Add new photos to the appropriate folder, then add their paths to `index.html`.

## Gallery Sections
- Creative includes People, Environment, Companions, and Digital Art.
- Environment is organized into expandable Travel, Spain, Living, and Orange categories.
- Tech includes Infrastructure, Tech Stack, and GitHub Repos.
- GitHub project cards link to both live sites and repositories.

## Customize
- Update project names and descriptions in `index.html`.
- Replace the contact email and social `#` links.
- Open `index.html` directly in a browser.

The Creative / Tech switch changes the visual theme and filters the project grid. Click gallery images to open the lightbox preview.
